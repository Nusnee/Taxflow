กฎหมายที่เกี่ยวข้องกับแต่ละบทบาท

สรุปหน้าที่ตามกฎหมายของอินฟลูเอนเซอร์ บริษัท (Brand) และเอเจนซี่ ในการทำงานร่วมกันและใช้เอกสารอิเล็กทรอนิกส์

กฎหมายอินฟลูเอนเซอร์บริษัท (Brand)เอเจนซี่ (Agency)
ประมวลรัษฎากร ✓ เสียภาษีเงินได้บุคคลธรรมดา และรับหนังสือรับรองหักภาษี ณ ที่จ่าย (50 ทวิ) ✓ หักภาษี ณ ที่จ่าย ออก 50 ทวิ และเสียภาษีนิติบุคคล ✓ หักภาษี ณ ที่จ่าย ออก 50 ทวิ และเสียภาษีนิติบุคคล
พ.ร.บ.ภาษีมูลค่าเพิ่ม (VAT) ✓ หากจดทะเบียน VAT ต้องออกใบกำกับภาษี ✓ จด VAT (ถ้าเข้าเกณฑ์) ออกใบกำกับภาษีและยื่น ภ.พ.30 ✓ จด VAT (ถ้าเข้าเกณฑ์) ออกใบกำกับภาษีและยื่น ภ.พ.30
พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล (PDPA) พ.ศ. 2562 ✓ ยินยอมให้ใช้ข้อมูลส่วนบุคคล ✓ เก็บ ใช้ และเปิดเผยข้อมูลผู้ใช้อย่างถูกต้อง ✓ เก็บ ใช้ และเปิดเผยข้อมูลผู้ใช้อย่างถูกต้อง
พ.ร.บ.ธุรกรรมทางอิเล็กทรอนิกส์ พ.ศ. 2544 ✓ ลงนามและทำสัญญาออนไลน์ได้ ✓ ใช้เอกสารและสัญญาอิเล็กทรอนิกส์ได้ ✓ ใช้เอกสารและสัญญาอิเล็กทรอนิกส์ได้
ประมวลกฎหมายแพ่งและพาณิชย์ ✓ ปฏิบัติตามสัญญาจ้างและส่งมอบงาน ✓ ทำสัญญาว่าจ้าง ชำระค่าจ้างตามข้อตกลง ✓ ทำสัญญาและบริหารการจ้างแทนลูกค้า
พ.ร.บ.ลิขสิทธิ์ พ.ศ. 2537 ✓ เป็นเจ้าของผลงาน เว้นแต่มีการโอนสิทธิ์ตามสัญญา ✓ ใช้ผลงานตามสิทธิ์ที่ได้รับ ✓ จัดการสิทธิ์การใช้ผลงานตามสัญญา
พ.ร.บ.ว่าด้วยการกระทำความผิดเกี่ยวกับคอมพิวเตอร์ พ.ศ. 2550 ✓ ใช้งานระบบโดยไม่กระทำผิดกฎหมาย ✓ ดูแลความปลอดภัยของข้อมูลในระบบ ✓ ดูแลความปลอดภัยของข้อมูลในระบบ

1สรุปหน้าที่ของอินฟลูเอนเซอร์

  • ภาษี (ประมวลรัษฎากร): เสียภาษีเงินได้บุคคลธรรมดาจากค่าจ้างรีวิว/ผลิตเนื้อหา — เก็บหนังสือรับรอง 50 ทวิ จากผู้ว่าจ้างทุกราย ใช้เป็นเครดิตภาษีตอนยื่น ภ.ง.ด.90/94
  • VAT: หากรายได้เกิน 1.8 ล้านบาท/ปี ต้องจดทะเบียน VAT และออกใบกำกับภาษีเต็มรูป
  • สัญญา (แพ่งและพาณิชย์): ปฏิบัติตามสัญญาจ้าง ส่งมอบงานตามกำหนดและขอบเขตที่ตกลง
  • ลิขสิทธิ์: เป็นเจ้าของผลงานที่สร้าง เว้นแต่สัญญาระบุการโอนสิทธิ์ — ระวังการใช้เพลง/ภาพ/ฟอนต์ที่ติดลิขสิทธิ์ผู้อื่นในงาน
  • PDPA: ให้ความยินยอมการใช้ข้อมูลส่วนบุคคล (ชื่อ เลขภาษี บัญชีธนาคาร) แก่ผู้ว่าจ้างเท่าที่จำเป็น
  • ธุรกรรมอิเล็กทรอนิกส์: ลงนามสัญญาและรับเอกสารออนไลน์ได้ มีผลตามกฎหมาย
ใช้ TaxFlow: บันทึก 50 ทวิ ทุกใบเข้าระบบ → ดูยอดรายได้สะสม + ประมาณการภาษีทั้งปี → เก็บไฟล์ ภ.ง.ด.90/94 และใบเสร็จในคลังเอกสาร

2สรุปหน้าที่ของบริษัท (Brand)

  • ภาษี: เมื่อจ่ายค่าจ้างอินฟลูเอนเซอร์ ต้องหักภาษี ณ ที่จ่าย (โดยทั่วไป 3% สำหรับค่าจ้างทำของ/บริการ) ออกหนังสือรับรอง 50 ทวิ ให้ผู้รับเงิน และนำส่งด้วยแบบ ภ.ง.ด.53 (นิติบุคคล) — เสียภาษีนิติบุคคลประจำปีด้วย ภ.ง.ด.50 และครึ่งปีด้วย ภ.ง.ด.51
  • VAT: จดทะเบียน VAT เมื่อเข้าเกณฑ์ ออกใบกำกับภาษี และยื่น ภ.พ.30 รายเดือน — เก็บ ภ.พ.20 ไว้แสดงสถานะผู้ประกอบการ
  • สัญญา: จัดทำสัญญาจ้าง Influencer เป็นลายลักษณ์อักษร ระบุขอบเขตงาน ค่าตอบแทน กำหนดจ่ายเงิน และการใช้สิทธิ์ผลงาน — ชำระเงินตามข้อตกลง
  • ลิขสิทธิ์: ใช้ผลงานได้เฉพาะตามสิทธิ์ที่ได้รับในสัญญา (เช่น ระยะเวลา แพลตฟอร์ม) การใช้เกินสิทธิ์เป็นการละเมิด
  • PDPA: เก็บข้อมูลส่วนบุคคลของอินฟลูเอนเซอร์ (บัตรประชาชน บัญชีธนาคาร) อย่างปลอดภัย ใช้ตามวัตถุประสงค์ และลบเมื่อหมดความจำเป็น
  • คอมพิวเตอร์ 2550: ดูแลความปลอดภัยระบบข้อมูล ป้องกันการเข้าถึงโดยมิชอบ
ใช้ TaxFlow: ออก e-Withholding ทุกครั้งที่จ่ายค่าจ้าง → เก็บสัญญาจ้าง/PO/ใบส่งมอบงาน/หลักฐานโอนเงินครบวงจรในคลังเอกสาร → ส่งออก CSV ประกอบการยื่น ภ.ง.ด.53

3สรุปหน้าที่ของเอเจนซี่ (Agency)

  • ภาษี: หน้าที่เช่นเดียวกับบริษัท — หัก ณ ที่จ่ายเมื่อจ่ายค่าจ้างอินฟลูเอนเซอร์ ออก 50 ทวิ นำส่ง ภ.ง.ด.53 ยื่น ภ.พ.30 (ถ้าจด VAT) และภาษีนิติบุคคล ภ.ง.ด.50/51
  • สัญญา 2 ชั้น: บริหารสัญญาทั้ง 2 ด้าน — สัญญากับแบรนด์ (รับจ้างบริหารแคมเปญ) และสัญญากับ Influencer (จ้างช่วงผลิตเนื้อหา) เงื่อนไขต้องสอดคล้องกัน โดยเฉพาะเรื่องสิทธิ์ผลงานและกำหนดชำระเงิน
  • ลิขสิทธิ์: เป็นตัวกลางจัดการสิทธิ์ — ตรวจว่าสิทธิ์ที่ได้จากอินฟลูเอนเซอร์ครอบคลุมสิ่งที่สัญญากับแบรนด์สัญญาไว้
  • PDPA: ถือข้อมูลส่วนบุคคลของอินฟลูเอนเซอร์จำนวนมาก (บัตรประชาชน สมุดบัญชี) — ต้องมีมาตรการเก็บรักษา จำกัดการเข้าถึง และเปิดเผยเท่าที่จำเป็นต่อแบรนด์
  • นิติบุคคล: เตรียมเอกสารบริษัทให้พร้อมใช้เสมอ: หนังสือรับรองนิติบุคคล ภ.พ.20 หนังสือมอบอำนาจ บัตรผู้มีอำนาจ สมุดบัญชีบริษัท — ลูกค้าองค์กรมักขอตอนเปิด vendor
  • ธุรกรรมอิเล็กทรอนิกส์: ใช้เอกสาร/สัญญาอิเล็กทรอนิกส์และลายมือชื่อดิจิทัลได้ตามกฎหมาย
ใช้ TaxFlow: แยกหมวดคลังเอกสาร 3 กลุ่ม (บริษัท/ภาษี/ดำเนินงาน) ตรงกับเอกสารที่ลูกค้าองค์กรขอ → ออกใบกำกับภาษีให้แบรนด์ + e-Withholding ให้อินฟลูจากระบบเดียว

ข้อจำกัดความรับผิดชอบ: เนื้อหานี้เป็นการสรุปเพื่อการศึกษาในโครงงานระบบต้นแบบ ไม่ใช่คำแนะนำทางกฎหมาย — อัตราภาษี เกณฑ์ และหน้าที่ตามกฎหมายอาจเปลี่ยนแปลง โปรดตรวจสอบกับกรมสรรพากร (rd.go.th) หรือที่ปรึกษาภาษีก่อนดำเนินการจริง
